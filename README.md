# AMAR HEADSHOT PANEL PRO

A lightweight Android helper app for Redmi Note 12 5G and Free Fire practice.

## Included
- Sensitivity sliders with local save
- HUD/fire-button sizing guide
- Headset and directional-audio practice tips
- Device optimization checklist
- Headshot drag and training routine

## Safety
This app is a settings/practice helper only. It does not read, modify, inject into, automate, or interact with Free Fire. It does not provide an aimbot, auto-headshot cheat, anti-ban bypass, or guarantee of account safety.

## Build an APK
This project source is provided; a compiled APK is not included because the build environment used to create this package does not have the Android SDK or Gradle installed.

1. Install Android Studio on a computer.
2. Open this folder in Android Studio.
3. Let Android Studio sync the Gradle project and install any requested Android SDK platform (API 35).
4. Choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Find the output at `app/build/outputs/apk/debug/app-debug.apk`.
6. Transfer that APK to the Redmi Note 12 5G and install it. Only install APKs you built or trust.

## Requirements
- Android Studio with JDK 17
- Android SDK Platform 35
- Android Gradle Plugin 8.6.1
